# 坦克大战 · 栗子游戏网

仿 FC《坦克大战》(Battle City) 的单人网页小游戏，单个 HTML 文件，纯 Canvas 实现，无外部依赖。

在线试玩：https://jiaoyi.ximutan.com/tank-battle/

## 玩法

- 方向键 / WASD 移动，J / 空格 开火，Enter 开始 / 暂停，M 静音
- 保护底部老鹰基地，消灭每关 20 辆敌军
- 砖墙可打穿，钢墙永远打不穿；水不能过，草丛可隐蔽
- 闪红的敌军被击中会掉道具：星星、手雷、盔甲、铁锹、时钟、加命
- 吃到盔甲期间坦克不会被击毁

## 本地运行

直接用浏览器打开 `index.html` 即可。
